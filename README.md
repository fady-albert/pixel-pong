
# PIXEL PONG 

PIXEL PONG is a simple two-player game inspired by the classic Pong arcade game. I built it using HTML, CSS, and JavaScript as a fun project to practice JavaScript and learn more about working with the Canvas API.

The idea is simple: control your paddle, keep the ball in play, and try to score more points than your opponent. The first player to reach 5 points wins!

## How to Play

- Click **START** to begin the game.
- Player 1 controls the paddle using `W` and `S`.
- Player 2 uses the `↑` and `↓` arrow keys.
- Try to hit the ball and prevent it from passing your paddle.
- Score points by getting the ball past your opponent.
- The first player to score 5 points wins.

## Features

- Two-player gameplay on the same keyboard.
- Smooth ball and paddle movement.
- Ball collision with walls and paddles.
- Automatic score tracking.
- Winner screen when a player reaches 5 points.
- Option to restart and play again.
- Simple retro-inspired design.

## Built With

- HTML5
- CSS3
- JavaScript
- Canvas API

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/fady-albert/pixel-pong.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.
